# SPEC — Spamton NEO Battle Clone

Спецификация боя со Spamton NEO (Deltarune, Chapter 2) для клона.
Всё, в чём нет уверенности на 100% (не нашёл точных цифр/датамайна или
это зависит от прохождения), помечено **[ПРОВЕРИТЬ]**. Пожалуйста,
поправьте это до начала кодирования — этап 0 на этом и заканчивается.

Источники, которыми пользовался (веб-поиск, т.к. прямой доступ к вики
из этой песочницы заблокирован политикой сети — фетчился только
сниппет поиска, не полные страницы):
- Deltarune Wiki / Fandom (через поисковые сниппеты)
- NamuWiki (Spamton NEO/전투)
- Cyberpedia (Undertale & Deltarune encyclopedia)
- Обсуждения Steam Community по бою

**Важно:** ниже я специально не привожу дословные реплики Спамтона —
только структуру диалогов. Сам текст реплик должен быть либо вписан
вами в `dialogue.json` из легального источника, либо я напишу
трансформативный текст «в стиле персонажа» (не дословную копию) — это
нужно решить отдельно, см. раздел «Диалоги и копирайт».

## 0. Ключевая находка, которая меняет постановку задачи

В исходных технических требованиях предполагалось, что:
1. Бой начинается с обычного (маленького) Spamton, который трансформируется в NEO прямо в середине сражения.
2. У NEO есть обычная шкала Mercy → в какой-то момент открывается кнопка SPARE.

Оба пункта **не соответствуют оригиналу**:

1. Трансформация в NEO происходит **до** боя, в кат-сцене (Крис
   вставляет "Loaded Disk" в старую машину в подвале особняка
   Queen). Бой начинается уже с полноформенным NEO, через гэг с
   телефонным звонком ("это тебе звонят" / "мне?!"), и сразу
   переходит к его декларации "Power of NEO" / "Big Shot". Отдельный
   маленький Spamton — это **другой, более ранний** бой в его
   магазине, который в клон NEO-боя не входит (если вы не попросите
   иначе).
2. Spamton NEO **нельзя "заспарить" обычной кнопкой SPARE** — по
   нескольким независимым источникам он прямо помечен как
   "cannot be spared". Вместо этого у него **альтернативная, не
   FIGHT-центричная концовка через ACT**: команды `Snap` (перерезать
   одну нить/струну), плюс контекстные ACT-действия персонажей
   (условно `S-Action` у Susie, `R-Action` у Ralsei) поднимают
   скрытый процент **Mercy** (~2% за обычное действие, ~7% за
   `Snap All`, где доступно). Когда все нити перерезаны, кроме
   последней — скриптовая сцена: NEO понимает, что его пытаются
   освободить, благодарит, просит перерезать последнюю нить — и
   падает без опоры. За это даётся уникальная награда (броня
   "Dealmaker": DEF + доп. золото).

**[ПРОВЕРИТЬ] Решение, которое нужно от вас:** какой вариант делаем?

- **Вариант A (точнее к оригиналу):** нет кнопки SPARE вообще; есть
  вторая победная концовка через ACT/Snap → Mercy% → «мирная»
  победа. Более интересно и аутентично, но сложнее в реализации
  (нужна логика процентов, отдельная сцена финала).
- **Вариант B (проще, как в тех. задании):** держим классическую
  Undertale-схему — Mercy-полоска растёт от урона/ACT, при
  достижении порога открывается обычная кнопка SPARE. Менее точно к
  первоисточнику, но проще и ближе к тому, что вы изначально описали
  и что действительно похоже на механику из sansflowey/bad-time.

Дальше в спеке я описываю **оба** варианта параллельно (Вариант A как
основной/рекомендуемый, Вариант B как fallback), но реализовывать
будем только один — скажите, какой.

## 1. Структура боя (машина состояний верхнего уровня)

```
Boot
 └─ StartMenu ("Начать игру" / "Начать сразу с боя")
Intro
 ├─ PhoneCallGag        (телефон, гэг "это тебе звонят")
 ├─ NeoDeclaration      ("Power of NEO", "Big Shot" спич)
 └─ [пропуск: удержание C 1 сек ИЛИ пункт стартового меню]
BattleLoop
 ├─ PartyMenu           (по очереди Kris → Susie → Ralsei)
 │   ├─ FIGHT → полоска тайминга → урон
 │   ├─ ACT → подменю действий персонажа
 │   ├─ ITEM → подменю предметов
 │   ├─ DEFEND → пропуск атаки, +TP, снижение входящего урона
 │   └─ SPARE (только Вариант B, см. выше)
 ├─ ResolveTurn          (применяем выборы всех троих)
 ├─ EnemyAttack          (жёлтая душа, один из паттернов атак)
 ├─ CheckWinLose
 │   ├─ HP NEO ≤ 0             → VictoryFight
 │   ├─ Mercy% = 100 (Вар. A)  → VictoryWires
 │   ├─ Mercy = MAX (Вар. B)   → SpareButton доступен → Victory
 │   └─ HP всей партии = 0     → GameOver
 └─ иначе → назад в PartyMenu
Victory (эпилог + возврат в StartMenu)
GameOver (эпилог + Retry)
```

**[ПРОВЕРИТЬ]** Точная последовательность ходов: в оригинале ходят
все три персонажа за один "раунд", затем один ход атаки врага —
предполагаю такую схему (стандартная для Deltarune), уточните, если
не так.

## 2. Статы

### Spamton NEO
- HP: **4809**
- ATK: **13**
- DEF: **0** (обычный маршрут) / **-27** (Weird Route, не входит в
  scope, если не скажете иначе)
- DEF на обычном маршруте **уменьшается на 3 каждый ход после хода
  №16**, до минимума **-12**. Механика роста уязвимости к концу боя.
- **[ПРОВЕРИТЬ]**: не нашёл точных порогов HP, при которых меняются
  фазы/паттерны атак (см. раздел 5) — предлагаю привязать фазы к
  проценту оставшегося HP как разумное приближение (100–75% / 75–40%
  / 40–15% / <15%), поправьте, если знаете точки лучше.

### Партия (Kris / Susie / Ralsei)
- В Chapter 2 партия имеет **LV2** к этому моменту (LV3 — уже после
  GIGA Queen, то есть после этого боя).
- Точные базовые HP на LV2 не нашёл достоверно, а реальное значение
  **зависит от прохождения** (не-летальные/летальные победы над
  обычными врагами дают +2 HP Kris/Susie/Ralsei, Susie доп. +1 раз в
  два боя) — то есть в самой игре нет одного "канонического" числа.
- **[ПРОВЕРИТЬ] Предлагаю** зафиксировать для клона удобные круглые
  числа (не претендуя на 100% точность игры, т.к. её и не существует
  в общем случае):
  - Kris HP: **90**
  - Susie HP: **112**
  - Ralsei HP: **80**
  - Общий TP: шкала **0–100%**, +TP за DEFEND и за получение урона.
- Скажите, если у вас есть точные цифры из конкретного сохранения,
  которое хотите воспроизвести — впишем их.

## 3. Меню боя

Как в Deltarune: у каждого персонажа свой ход, меню выбора действия
для него, потом ход разрешается сразу для всех выбранных действий
одновременно (не по одному).

| Пункт | Kris | Susie | Ralsei |
|---|---|---|---|
| FIGHT | ✔ (обычная полоска) | ✔ (обычная полоска, оружие — топор, урон выше) | ✘ (Ralsei физически не атакует, у него по каноничной механике нет FIGHT — **[ПРОВЕРИТЬ]**) |
| ACT | CHECK, SNAP (Вариант A) | CHECK, SNAP, S-ACTION | CHECK, SNAP, R-ACTION |
| ITEM | ✔ | ✔ | ✔ |
| DEFEND | ✔ | ✔ | ✔ |
| SPARE | только Вариант B | только Вариант B | только Вариант B |
| Спец. умение (тратит общий TP) | **[ПРОВЕРИТЬ]** — в реальном бою у Susie/Ralsei есть TP-скиллы (Rude Buster, групповое лечение и т.п.); нужно ли включать в клон? Предлагаю добавить упрощённо: Susie "Rude Buster" (урон), Ralsei "Heal Prayer" (лечение партии) — да/нет? |

- **CHECK** — показывает HP%/ATK/DEF NEO плюс одну строчку флейвор-текста.
- **SNAP** — основное действие для Mercy% (Вариант A): "перерезать нить".
- **S-ACTION / R-ACTION** — уникальные для персонажа реплики/действия,
  тоже поднимают Mercy% на меньший процент. **[ПРОВЕРИТЬ]** точные
  названия и что именно они "делают" визуально — не нашёл описания,
  предлагаю: S-ACTION = "Оскорбить" (Susie дерзит), R-ACTION =
  "Подбодрить" (Ralsei подбадривает Спамтона по-доброму).
- **Snap All** — появляется отдельным пунктом только когда снято
  достаточно нитей вручную (либо когда Mercy% ≥ некоторого порога).
  Даёт крупный прирост (**~7%** по источникам).

## 4. Механика души

### Красная душа (свой ход)
Во время выбора действий в меню — обычная Undertale/Deltarune схема,
отдельной души на экране нет (не тратим на это ресурсы полировки).

### Жёлтая душа (ход врага) — фирменная механика этого боя
- Всегда (или почти всегда — см. ниже "cart"-атаки) душа **жёлтая**.
- Управление: стрелки/WASD — движение по battle box; **Z/Enter** —
  выстрел вверх; **удержание Z** — заряд **Big Shot** (более сильный/
  крупный снаряд, уничтожает больше целей за раз); **X/Shift** — как
  и в обычном Undertale-движении, доп. точное/медленное перемещение
  **[ПРОВЕРИТЬ]** — не уверен, что в NEO-файте вообще есть
  "медленный шаг" отдельно от обычного, возможно душа тут не имеет
  этого модификатора вовсе, т.к. и так постоянно двигаешься и
  стреляешь.
- **Хитбокс душа < спрайта**, как в ТЗ.
- **Кадры неуязвимости** после попадания + мигание — стандартно.
- Основная цель во время атаки: **сбивать синие снаряды/цели**
  выстрелами. Несбитая цель может "размножиться"/вызвать эскалацию
  (например, Pipis, не сбитый до касания верха бокса, лопается на 4
  маленькие головы Спамтона, которые тоже нужно либо сбивать, либо
  уворачиваться).
- **Big Shot** также используется как "толчок" — попадание заряженным
  выстрелом отбрасывает вражеские объекты назад (например, голову с
  телефонными руками, которая иначе доползает и наносит урон).

### "Cart"/lane-режим (отдельный подтип атаки)
В части атак (описано ниже — "Lane Dodging", "Trucks") душа не
свободно двигается по всей коробке, а **переключается между
несколькими дорожками/полосами** (похоже на "рельсовый" мини-раздел),
и цель — оказаться в полосе с безопасным символом, а не сбивать цели
стрельбой.

**[ПРОВЕРИТЬ]**: количество дорожек (3? 4? 5?), можно ли стрелять во
время cart-атак вообще, или это чисто dodge-режим. Предполагаю
dodge-only, без стрельбы, 4 дорожки (совпадает с "четыре копии головы
по одной дорожке за раз" из описания атаки).

### Коробка боя (battle box)
- Размер/форма меняются под конкретную атаку (сказано в задании и
  подтверждается источниками — "battle box attacks" дают больше
  места для движения, некоторые атаки блокируют игрока в
  уменьшенном/особом боксе, при "Power of NEO" фон вообще гаснет в
  чёрный, и на передний план выезжает огромный NEO).
- **[ПРОВЕРИТЬ]** точные размеры на разных этапах — буду закладывать
  разумные пропорции (внутреннее разрешение 640×480, box ~ от
  300×150 до почти во весь экран для широких lane-атак).

Ниже — атаки, которые удалось подтвердить по описаниям (реальные

**[ПРОВЕРИТЬ] Общее число атак и порядок:** не нашёл официального
"списка всех атак по порядку" — вероятно, их больше (source-игра
известна большим разнообразием паттернов у NEO), и часть могла не
попасть в выдачу поиска. Предлагаю на старте реализовать эти 7 (без
Weird-route-эксклюзива), a затем добавлять новые как отдельные модули
в `src/attacks/` — архитектура это позволяет без переписывания ядра.

**Тайминги** атак (длительность, скорость снарядов, интервалы) —
данных не нашёл вообще, это придётся подбирать на глаз при
плейтесте и сверять с видео/оригиналом отдельно — тоже
**[ПРОВЕРИТЬ]**, я не смогу гарантировать fps-точное совпадение без
сверки с записью боя или датамайном (GML-скриптами).

### Известный баг оригинала — сознательно НЕ переносим
В оригинале есть клавиатурный эксплойт: зажатие одной клавиши +
нажатие/отпускание другой позволяет стрелять заряженными Big Shot без
"разрядки". Использование больше 5 раз злит NEO (урон от его атак
растёт, ATK +0.5 за каждый читерский выстрел, кап 26). Это баг, не
фича — **не реализуем** намеренно. Просто зафиксировал, чтобы не
удивлялись, если не найдёте это поведение в клоне.

## 6. Победа / поражение / "пощада"

- **Поражение:** суммарный HP партии (Kris+Susie+Ralsei) = 0 →
  GameOver-экран, кнопка "заново" (рестарт боя, не всей игры).
- **Победа через FIGHT:** HP NEO ≤ 0 → сцена поражения/разрушения,
  экран Victory.
- **Победа через ACT (Вариант A, рекомендую):** Mercy% доходит до
  100 через Snap/S-Action/R-Action/Snap All → уникальная сцена
  "падает без нитей" → экран Victory (другой текст/иконка, чем при
  FIGHT-победе) + пометка о "мирном" прохождении.
- **SPARE-кнопка (только Вариант B):** появляется, когда Mercy
  достигает порога **[ПРОВЕРИТЬ — предлагаю 100%, как в обычной
  Undertale-логике]**, выбор SPARE у любого живого персонажа сразу
  завершает бой победой.

## 7. Вступительный диалог — структура (без дословного текста)

1. `PhoneCallGag` — 2–4 короткие реплики, комедийная завязка про
   звонок.
2. `NeoDeclaration` — спич про "Power of NEO" / "Big Shot", подводка
   к первому ходу.
3. Каждая реплика — посимвольный вывод + звук "блип" на символ,
   **Z** — следующая реплика (или мгновенно закончить текущую
   строку, если ещё печатается — как в оригинале), **X** — сразу
   вывести реплику целиком.
4. Пропуск всего интро: удержание **C** 1 секунду (с визуальным
   индикатором заполнения) ИЛИ пункт "Начать сразу с боя" в
   стартовом меню.
